Условия на тело ?Проверка содержимого тела по dot notation:
user.name, items[0].id, items[*].status

Операторы: равно, не равно, содержит, существует

Значения: авто-типизация ("true" → true, "123" → 123)
Переменные: $varName подставит значение переменной

Подмена ответа / Модификация ответа → response body
Модификация запроса → request body

Условия на переменные ?Проверка значений переменных, сохранённых другими правилами.
Переменные живут в рамках одной вкладки и сбрасываются при F5.

Имена с префиксом $: $userId, $status

Советы

  • Правила применяются сразу без перезагрузки страницы
  • Если правило не сработало — попробуйте обновить страницу (F5)
  • Перехватываются только fetch и XMLHttpRequest
  • Мокированные запросы видны в консоли (F12 → Console) с тегом [MockerJoker]
