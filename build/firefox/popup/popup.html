URL-паттерны:

* — любое количество символов, ? — один символ

Пример: */api/users* перехватит все запросы, содержащие /api/users


Пресеты:

500 — ошибка сервера

403 — запрет доступа

401 — нет авторизации

204 — пустой ответ

Частичные данные — неполный JSON (отредактировать body)

Убрать Auth/Cookie — удалить заголовок из запроса


Задержка (мс):

Укажите в редакторе правила. 3000 = 3 сек, 30000 = 30 сек

Используйте для тестирования спиннеров и таймаутов


Советы:

- После создания правила перезагрузите страницу (F5)

- Перехватываются только fetch и XMLHttpRequest

- Мокированные запросы видны в консоли (F12 → Console)

- Экспорт/Импорт работает в полной панели
