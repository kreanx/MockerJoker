Справка

URL-паттерны:

* — любое количество символов

Пример: */api/users* перехватит все запросы, содержащие /api/users


Пресеты:

500 — ошибка сервера

403 — запрет доступа

401 — нет авторизации

204 — пустой ответ

Частичные данные — неполный JSON (отредактировать body)

Убрать Auth — удалить заголовок Authorization из запроса

Убрать CORS — удалить CORS-заголовки из ответа


Задержка (мс):

Укажите в редакторе правила. 3000 = 3 сек, 30000 = 30 сек

Используйте для тестирования спиннеров и таймаутов


Советы:

- Правила применяются сразу без перезагрузки страницы

- Если правило не сработало — попробуйте обновить страницу (F5)

- Перехватываются только fetch и XMLHttpRequest

- Мокированные запросы видны в консоли (F12 → Console) с тегом [MockerJoker]
